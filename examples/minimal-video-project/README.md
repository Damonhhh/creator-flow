# 最小视频项目

这是一个可复制的生产起点，不是一份假装完成的演示工程。创建后，你会得到选题阶段需要的个人输入、素材规划占位和完整目录；QA、人工验收与发布记录必须在实际生产中生成。

先完成四件事：

1. 在 `account-profile.md` 写清账号服务谁、持续讲什么、明确不讲什么。
2. 在 `writing-style.md` 放入你认可的表达习惯和真实改写样本。
3. 在 `knowledge-sources.md` 登记可以使用、需要复核和禁止公开的知识来源。
4. 核对 `source-content.md` 的选题结论与证据，再进入 Script TTS 阶段。

后续按六阶段推进：Topic → Script TTS → Material → Assembly → QA → Publish Wrap Up。不要提前填写 PASS，也不要把“文件存在”当成“已经验收”。
