# 写作风格

## 声音

- 希望观众觉得你像谁在说话：`请填写`
- 语气：`请填写，例如直接、克制、带判断`
- 句子节奏：`请填写，例如短句为主，复杂处允许两句解释`

## 保留与避免

- 必须保留的常用说法：`请填写`
- 不会使用的词和句式：`请填写`
- 开头习惯：`请填写`
- 结尾习惯：`请填写`

## 证据与观点

- 如何区分事实、推断和个人判断：`请填写`
- 引用来源时的说法：`请填写`
- 不确定时如何表达：`请填写`

## 真实样本

放入 3—5 组“机器初稿 → 你认可的改写”。这部分比抽象形容词更能稳定复现你的风格。

### 样本 1

- 初稿：`请填写`
- 你的改写：`请填写`
- 为什么这样改：`请填写`
