# 隐私边界

公开仓库包含共享脚本、Skill、规则、测试、示例和空配置模板。它只交付生产链路。

以下内容必须留在使用者本地：

- 真实账号定位、个人判断、私有评分规则和未公开选题。
- 写作样本、个人知识库、客户资料和内部内容资产。
- 声音样本、音色标识、模型缓存和生物特征相关材料。
- Cookie、Token、API Key、认证头、浏览器配置和上传凭据。
- 历史视频工程、平台账户名、发布记录与本机运行状态。

## 配置边界

- 公开仓库只提交 `*.example.json`；使用者复制出的 `*.local.json` 不进入 Git。
- 密钥只通过安全的环境变量或本地密钥设施提供，不写入文档、项目状态或发布包。
- 第三方 API Base 由 CLI、环境变量或 `providers.local.json` 明确提供，公开版本不内置中转地址。
- 示例素材必须可公开、已脱敏或由项目自行生成；“候选”不等于“可发布”。

公开文件由显式白名单导出。导出扫描会检查本机绝对用户路径、私有工作区路径和常见凭据格式；扫描通过只代表没有命中现有规则。发布前仍需人工检查 Git 文件列表、提交历史和最终发行包。
