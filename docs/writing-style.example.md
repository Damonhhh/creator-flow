# 写作风格输入模板

这不是一份“万能人设”。请用你已经发布过、自己也认可的内容，把下面的问题写具体。

## 我是谁

- 我长期做什么：
- 我亲自做过什么：
- 哪些话题我不会假装懂：

## 我在对谁说

- 读者现在卡在哪里：
- 他们已经知道什么：
- 哪些术语必须先解释：

## 我的表达习惯

- 我常用的句子长度：
- 我喜欢怎样开头：
- 我如何表达不同意：
- 我绝不会说的套话：

## 已确认的语言样本

放入三到五段你亲自写过、愿意继续沿用的文字。不要只写“自然、专业、有网感”这类抽象形容词。

## 最终检查

- 事实有没有被语气放大？
- 读者看完能带走什么具体东西？
- 有没有删掉空泛宣传、重复总结和公式化转折？
- 这段话像不像我真的会说出口？
