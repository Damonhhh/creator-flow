# TTS 自然节奏验收

适用于分段生成的长口播，也适用于克隆音色或其他 TTS 路线。

## 规则

- 不用长静音补时长。优先调整文本分段和段间连接。
- 以最终音频为准；音频重新生成后，必须重跑 ASR、SRT、字幕和场景时间线。
- 默认运行 `scripts\test-narration-pacing.ps1`。检测到异常长停顿时，回到 Script TTS 阶段；刻意停顿必须在 review 中说明。
- 脚本检测通过不等于听感通过。交付前仍要人工试听开场、段落衔接和收尾。

## 验收结果

记录所用 TTS 路线、分段方法、检测阈值、最长停顿和人工试听结论。不要记录私人参考音路径、声音身份或密钥。
